# CONGLOMERATE Ver.0.22.1 — 総合完成車工場の内製機能修正

**2026年11月17日・Ver.0.22からの互換修正版**

## 不具合の原因
Ver.0.22の詳細製造モードでは、総合完成車工場が最終組立専門工場と同じ判定を使用し、「エンジン・車体・電子制御の3部品が工場に到着していること」を完成車生産の必須条件としていた。このため、工場を保有していても3部品の到着在庫が0のとき、生産台数と稼働率が0になっていた。

## 修正内容
- **総合完成車工場：** 到着済み部品3点セットを優先使用し、不足分についてエンジン・車体・電子制御部品を同じ工場内で製造して、その月の完成車組立に投入。
- **必要原材料：** 内製による完成車1台あたり、車両本体の材料消費に**鋼材5単位・ゴム3単位**を追加。さらに部品加工賃金を計上。これらを材料・仕掛品・製品原価に反映。
- 内製部品は**その場で消費**するため、輸送・到着部品在庫には加算しない。工場詳細画面では「前月の内製台数」を独立表示。
- **最終組立専門工場：** 従来どおり外部配送されたエンジン・車体・電子制御部品が各1個ないと車両組立できない。
- **従来の共通部品方式：** 計算変更なし。
- **操作案内：** 工場が休止・建設・改修中、製造人員不足、生産計画が0、原材料不足の場合、原因候補を工場詳細に表示。調達画面への導線を追加。

## 互換性・検証
- 保存形式 `VERSION=1` 維持。800研究技術、M&A、株主・新株発行、工場の運用管理・自動輸送・月次診断、企業内IDを維持。
- 同条件で総合完成車工場は**到着部品0でも8台製造（8台分を内製）**。最終組立工場は到着0で0台、各8セット到着で8台製造。
- 総合工場に各2セット到着した場合、**2セット消費・残り6台分を内製**。
- 詳細方式の原材料不足では生産停止、従来方式の完成車組立は従来どおり。
- Ver.0.22で作成したJSONから復元し、**36か月連続**の単体・連結会計・連結キャッシュフロー検算に異常なし。JavaScript構文とChromiumブラウザ操作で検証。
- 実IndexedDBのブラウザ完全終了・再起動後の復元を全OS・全ブラウザで保証する試験は未実施。旧版から移行する場合はJSONバックアップ必須。

基本設計書Ver.3.0／SPEC-001〜094には変更なし。試作パラメータであり、実際の工場原価や現実の会計処理を保証しません。
