# 車種廃止の実装（開発ブランチ）

「製品・研究 → 車両設計 → 商品企画・車種管理 → 車種の生産・販売終了」で操作します。操作権限のある現行車種のみ廃止できます。改良・グレード開発中の車種は廃止できません。

- **在庫販売後廃止**：生産を0台に固定し、旧型車として完成車在庫と輸送中の商品を販売。すべて売り終えて輸送も完了すると販売終了になります。在庫がない場合は直ちに終了します。
- **即時販売停止**：生産を0台に固定し、その場で販売終了。完成車在庫と輸送中の未販売製品を台帳から除き、簿価を「その他費用 / 完成品・輸送中製品」に仕訳します。売上や現金は発生させません。

どちらも車種ID、販売履歴、品質保証・リコール情報を保存します。担当工場の固定割当を解除し、AIが対象車種の生産を再開しないようにします。車種の廃止方式・年月・決定時の在庫数量・即時廃止損簿価をJSONに保存します。BOM完成車ロットは既存の払出処理を再利用します。すでに国外輸送中の車も即時方式では廃棄扱いとなるため、確認画面で数量・簿価を示します。

回帰検査：`python -B tests/test_vehicle_discontinuation.py`。
