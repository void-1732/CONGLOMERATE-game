# CONGLOMERATE v0.10 — N4-B / G8-B / X1-B / 経営委任強化

開発版。基本設計書 Ver.3.0／SPEC-001〜094を維持し、質問91〜93・SPEC-095以降は未回答・未確定です。

## 機能
- **N4-B**：日本・米国・英国・ドイツ・フランスの5か国15都市・工業地域。地価、労働力、賃金、インフラ、輸送係数を比較し、工場建設立地を選択。建設費を設備資産／現金へ仕訳し、生産能力、製造人件費、維持費、搬送費に立地差を適用。
- **G8-B**：競合は成長・利益・品質・技術などの方針に応じて価格を約3か月ごとに見直し、研究、新型車開発、工場設備投資を実施。企業別に年間投資予算、最低資金留保、行動履歴を管理。
- **X1-B**：新規開始時に初期企業を30社へ拡充。5か国で業種・経営方針を分散し、地域別の需要と競合密度を参考に新規参入。退出した企業の法人ID・仕訳・所有者記録は維持。競合総数の仮上限は60社。
- **自動運営**：価格、調達先、工場保全、広告の4機能を個別に有効化。最低現金目標と月額支出上限を守り、取引は既存会計へ計上。買収・借入・新工場建設の自動承認なし。

## 回帰・性能検証
- Chromium/Playwrightによる30社初期化と15立地候補、立地別見積・投資仕訳、7か月の委任設定と追加支出制約。
- 120か月（10年間）の連続試験：30社で開始、39社まで増加。毎月の単体・連結会計、CF照合、JSONセーブ／復元のBS・CF一致を確認。
- 旧v0.9の保存形式に追加の所在地・競合方針・自動運営フィールドを補完。セーブ外枠 VERSION=1 と IndexedDB名は維持。
- 実ブラウザIndexedDBの完全終了・再起動後復元試験は**未実施**（自動テストは模擬DB）。

## 制限
- 立地の地価・賃金・技能・インフラ等は試作係数であり史実統計ではありません。
- 海外工場も法人会計通貨で保有・計上します。海外工場の独立倉庫、工場間実物輸送、法域別雇用・税・現地法人会計は未実装。
- 競合は経営ロジックの試作であり、実在企業の業績推定ではありません。
- 取得時正式PPA、税効果、のれん、完全な外貨換算調整勘定など未実装の会計論点は引き続き未確定。
- ユーザー承認なしに自動で株式発行、M&A、借入、工場増設は実行しません。
- 大企業群の120か月試験は通過していますが、100年以上・数百社の性能試験は未実施。
