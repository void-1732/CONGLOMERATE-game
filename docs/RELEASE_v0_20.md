# CONGLOMERATE Ver.0.20 — AI車種競争／供給障害／新株発行

**現行配布本体：index.html（2026-11-16）**

## AI車種・価格競争
- 独立AI企業が約3か月ごとに価格を見直し、直近販売・在庫・利益方針・車両原価を反映する。適用した価格は車種の販売価格として市場計算に反映。
- 開発費・投資上限・開発期間・現役車種枠を満たした場合、既存車両から別購買層向けの新型車を開発・発売。
- 市場・販売網 → 全世界分析に競合企業の現役車種数、代表価格、直近販売実績、戦略施策を表示。

## サプライヤー供給障害
- 供給元法人および7種類の資材ごとに設備故障、納入遅延、輸送障害、原材料不足を1〜3か月間発生。
- 供給能力、仕入単価、輸送リードタイムを変更する。期間終了後は供給能力を回復。
- 資材ごとに主仕入先・代替仕入先と安全在庫係数（1、1.5、2）を設定可能。主契約先の不足分を代替先の空き能力で補充。
- 障害の発生履歴、供給制限、単価上昇、企業別不足数量を供給網・輸入画面で確認。
- 注文時の価格、数量、到着月を輸送中資材に保存し、既存の材料費・買掛金に反映。

## 株式発行・資金調達
- 企業グループ → 株主・新株発行を追加。発行会社の新株引受人として銀行・投信保険・公的機関・個人投資家を選択。
- 既存株数の5〜35%を追加発行。価格は既存のM&A企業価値試算の80〜120%。一法人につき12か月に1回まで。
- 新株引受は資金を発行会社に入れるプライマリー取引であり、既存株主間のM&A株式売買や自己株式売却ではない。
- 現金／資本金の仕訳、発行済株数、全既存株主の議決権・経済持分の希薄化、外部株主合計・投資家別持分の再計算、発行履歴を実装。
- 支配下の子会社も発行可能。支配割合が過半数以下になれば既存の議決権支配判定で対象外となる。
- AI独立企業も資金状態に応じて自動増資を検討。

## 保存互換性
- 保存形式 VERSION=1 を維持。旧版JSONにないcapitalPolicy、sharesOutstanding、supplyRisk、代替契約は読み込み時に補完。
- 研究800技術、Ver.0.19までのM&A・連結会計・グレード・販売・研究ロードマップ・会社名変更などを維持。
- 旧版に戻す場合は新形式セーブとの相互互換を保証しない。更新前にJSONバックアップを取得すること。

## 実行済み検証
- JavaScript構文、Chromium操作、旧Ver.0.19 JSONの読み込み、800技術維持。
- 新株発行の現金・資本金・株主台帳一致、100%子会社の増資後74.0741%保有、M&Aで60%取得した後の新株発行で48%に希薄化・支配喪失。
- 主仕入先の能力ゼロ試験で代替先から59単位を発注、AI新車開発・価格変更・品質・月末処理。
