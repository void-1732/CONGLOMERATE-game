# v0.5 取得時会計・外貨換算・連結財務の精度向上

## 実装
- 従来の帳簿価額基準の取得差額・固定基準レート連結試算を残し、比較用に維持
- 取得時スナップショット（取得対価、取得時純資産、取得時通貨換算レート）から暫定取得差額を計算
- **全資産・全負債の期末レート換算**を行う補助連結BSを新設。現金は既存のCF期末換算と一致するか照合
- **取引認識時レートで計算する直近確定月のPL**を新設し、月次確定履歴に保存
- 支配獲得前の取引を当月PLから除外し、後日の買収操作で既確定月のPL・CFを再計算しない
- グループ内商品売買の内部売上消去・期末在庫未実現利益の繰延・外部販売時の繰延解除
- 会社間貸付債権・債務の期末換算差を注記で表示（原因未解決なら架空の利益にしない）
- JSONセーブ形式 VERSION=1 / IndexedDB構造を変更せず、v0.4との互換性を保持

## 未完了と会計上の制約
- 取得時の**公正価値配分（PPA）、税効果、正式のれん・割安購入益**は未確定／未実装
- 親会社資本の歴史的レート換算、**為替換算調整勘定（OCI）を含む完全な連結BS/PL/CF間の橋渡し**は未完成
- 間接持分・非支配株主持分の全ケース（追加取得、支配喪失、循環、複数所有経路）の会計精度は未完成
- 内部債権債務の異通貨残高差、仕訳ベースの正式な連結調整には未処理部分がある
- 現在の補助連結BSは**資産−負債を純資産として計算する試算**。差額ゼロは各調整を独立に検証した証明にはならない
- 実ブラウザのIndexedDBを用いた**ページ再読込・完全再起動の受入試験は未完了**。自動試験は模擬データベース利用
- ゲーム内の経済係数・会計期間・価格などの多くは仮設定。監査済み会計基準準拠の財務諸表ではない
