# CONGLOMERATE v0.18 — M&A・AI買収・PMI

- 候補企業を国・業態・所有状態・企業評価額で絞り込み、純資産・売上・利益・負債・工場・従業員・研究水準を確認。
- 取得比率・提示倍率による買収額計算と外部株主の売却条件に応じた交渉を追加。
- 自社グループ保有株式／ゲーム内企業株主／外部株主（銀行・政府系・機関投資家・個人）／自己株式を明確に区分。
- AI企業による半年ごとのM&A判断と、支配取得後の6か月間のPMI経営統合を実装。
- 法人格・既存債務を保つ経営統合であり、法的吸収合併ではありません。企業株主からの個別譲渡や新株発行は未実装。
- 取得55%→追加45%で100%保有、AI買収、月次・連結検算などを検証。
