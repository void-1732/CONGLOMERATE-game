# CONGLOMERATE v0.27.1 — 工場別生産配分・自社株買い

## 実装した機能
- 工場ごとの実配置製造人員・設備・状態から有効能力を計算。無人工場は完成車を生産できません。
- 工場ごとの有効能力に比例して各車種の生産計画を按分し、余剰能力へ再配分。先頭工場への偏りを解消しました。
- 既存の詳細部品製造（総合工場での3モジュール内製）と従来共通部品方式の両方を保持。
- 企業グループ → 株主・資本政策に、外部株主からの自社株買い（1〜20%、提示倍率80〜150%）、議決権対象から自己株式の除外、自己株式消却、履歴を追加。
- 買戻しは現金を減らし、自己株式を純資産控除として仕訳。売上・費用へ混入しません。買戻し後の新株発行も議決権分母を補正。
- 取得対象株式不足、株主売却留保倍率、資金不足、12か月のクールダウンは拒否。買戻し・消却は試算後に確認し、検算を通過した状態のみ確定。

## 動作検証（Chromium）
- 研究800技術、Node.js構文確認、旧v0.27の読み込み／保存。
- 2工場の配置0人/70人で、従来・詳細両方式とも生産0台/25台。月次の実行もそれぞれ2か月検証。
- 40人/40人配置の均等工場で、生産25台を13台/12台へ配分。
- 自社株買いと自己株式消却、新株発行との併用、企業株主を含む株主構成の議決権計算、保存再読込を確認。
- 不正入力・資金不足・12か月以内の再実行は拒否、拒否時の状態変更なし。
- 60か月の通常シナリオで単体・連結会計、連結CF検算合格。390px画面の横方向はみ出しなし。

## スコープと制限
- このリリースは **Ver.0.27.1**。NEXT-001〜012の長期改修ロードマップを保持し、Ver.0.28〜0.29のBOM設計・ライセンス・多通貨財務・提携などの実装済みを意味しません。
- 自社株買いは外部株主クラスに対する試算価格での取得に限定。公開市場の板取引、法人株主からの個別取得、現実の法律・税務の精密再現は未対応。
- 生産停止の原因は原材料不足、部品未到着、設備停止、計画0、人員不足等もあり、すべての工場の稼働を保証するものではありません。
- 元セーブをJSONでバックアップしてください。新形式の自社株買いセーブを旧v0.27へ戻す動作は保証しません。
