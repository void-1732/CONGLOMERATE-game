# CONGLOMERATE v0.13 — 時代別費用・研究ツリー拡張

基本設計書 Ver.3.0 と SPEC-001〜094 を保持。質問91〜93およびSPEC-095以降は未確定です。

## 変更
- 研究を**3上位カテゴリ・10分野・各2〜3系統**に再配置。各分野30技術、合計300技術。技術前提は同系統・異系統・異分野に渡ります。研究効果は性能、品質、生産効率に集約。
- 新分野：エネルギー・蓄電、電子・制御技術、ソフトウェア・自動運転、環境・資源循環。水素、PHEV、電子制御駆動、高度運転支援、コネクテッド内装などの設計選択肢を技術研究で解放。
- 研究枠の時代上限：1900年1枠、1930年2枠、1955年3枠、1980年4枠、2005年5枠、2030年6枠、2060年7枠。実際の枠は研究者数と実質研究予算の双方で制限。
- 基準年代を超えて先取りする技術は、より大きい時間ペナルティと前提研究が必要。
- 工業費用指数：1900年を1、年率約1.8%の試作係数、最大36倍。工場建設・維持、車両開発・維持、製造人件費、採用、部品加工、工場間物流、競合の研究・設備投資に反映。資源価格変動も製造原価に反映。
- 新規ゲームの後年開始資本・初期車両価格・競合資本も名目費用上昇に応じて調整。

## 未実装・限界
費用指数や技術の基準年はゲームバランス用の暫定値であり、歴史的統計や正式仕様ではありません。実IndexedDBのブラウザ終了・再起動による保存耐久試験は未実施（JSONとモックDBのみ）。正式なPPA、外貨換算調整勘定、複雑な企業内実物流・移転価格、法的吸収合併等の課題は引き継ぎます。100年以上の長期耐久試験は未実施です。
