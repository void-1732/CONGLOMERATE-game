# CONGLOMERATE v0.6 — ゲーム体験改善（第1弾）

**正式設計書：Ver.3.0 / SPEC-001〜094 維持。** 設計質問91〜93とSPEC-095以降は未回答・未確定です。新規改善の質問1（画面構成）と質問5（企業グループ/M&A）も保留し、根幹を決め打ちしていません。

## 承認済みの3方針と実装
1. **質問2 B｜9項目の車両設計**：車体、購買層、車格、動力方式、出力、駆動、乗り味、安全・品質、内装装備を設定。製品開発プロジェクトへ保存し、発売後に性能・品質・材料使用量・工程負荷・市場適合へ反映。技術・年代による制限と事前プレビュー。
2. **質問3 B｜工場別管理**：一法人が複数工場を所有可能。小／中／大規模、総合／組立／エンジン／車体／部品専門機能、工期・投資費用・固定維持費・設備状態・保守・車種割当・工場別月次生産実績。支援工場は完成車を直接生産せず、完成車生産能力の補助係数へ反映。
3. **質問4 B｜6研究分野**：動力・エンジン、車体・駆動、材料・軽量化、安全・品質、快適性・装備、生産・工程技術。前提条件・技術レベル・研究予算・研究者数・進捗・成果を表示。研究変更時の進捗率リセットは試作挙動。

## 既存確定要件の補完
- 国別・モデル別の**自社販売分析**を既存の「市場・世界経済」ページへ追加。確定月の地域需要参考値と実販売を表示。
- 「月次レポート」内の余分な月末処理ボタンを撤去。画面上部の「月末処理」→事前確認→確定は維持。
- **セーブ互換**：JSON外枠の VERSION=1 を維持。旧v0.5の単一工場および建設中拡張を工場配列へ移行し、研究情報・販売分析履歴の欠落値を補完。旧データからのインポート前には必ずJSONバックアップを取ること。
