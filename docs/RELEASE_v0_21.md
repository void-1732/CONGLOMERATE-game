# CONGLOMERATE Ver.0.21 — 高度工場運営・自動輸送・月次処理診断

**最新ゲーム本体：`index.html`**（2026年11月16日、開発試作版）

## 工場設備の管理

- **設備更新：** 設備水準を第1〜4世代まで向上。工事2か月、投資費用は固定資産として計上。
- **拡張：** 工場能力を約30%拡張。工事3か月、工事中の設備は生産を休止。
- **縮小：** 工場の生産能力を約25%削減。残存簿価の一部を処分損失・回収現金に反映。
- **休止・再開：** 稼働能力から外し、維持費を軽減（ゼロにはならない）。
- **廃止：** 工場を削除し、固定費負担を終了。工場内に専門部品在庫や輸送中の荷物がある場合は実行しない。
- 価格・会計・設備世代はゲーム用の試作係数。個別設備の厳密な法定減価償却台帳ではない。

## 詳細製造・専門部品

- 旧セーブの初期状態は**従来の共通部品方式**。任意で詳細方式に変更可能。
- エンジン工場／車体工場／部品工場で、それぞれエンジンユニット・車体モジュール・電子制御モジュールを製造。
- 鋼材・ゴムと加工費を実際に消費。組立工場で完成車1台につき各モジュール1個を使用。
- 送付前・輸送中・組立工場到着後の在庫区分と原価仕訳を保持。

## 支援工場から最終組立工場への自動輸送

- 工場ごとに**月次製造量、納入先、組立先の目標在庫、月間輸送上限、自動輸送ON/OFF**を設定できる。
- 自動補充量＝目標在庫−現地在庫−輸送中数量を基本として決定。不足部品と輸送運賃の現金を確認し、余力がなければ当月出荷を見送る。
- 立地別基本運賃（1900年基準・補正前）：**同一工業地域12円/個・1か月、国内別地域48円/個・2か月、国際180円/個・3か月**。年代費用係数と立地運賃係数を適用。
- 運賃は発送時の営業費用、部品の帳簿価額は輸送中材料として管理し、到着時に組立拠点在庫へ振替。
- 自動輸送は現在、同一企業が保有する工場間を対象とする。

## 月次処理中断エラーの診断

- 処理工程を個別に識別。失敗月、工程名、エラーID、関連する企業・工場、原因、処理前と途中の検算、直前のイベントを表示。
- 「診断ログをコピー」「診断ログを保存」「関連画面へ移動」「閉じた後の再表示」を実装。
- **月次計算の途中で失敗した場合は前のゲーム状態に戻す**。確定後の自動保存失敗は別扱いにし、誤った二重実行を防ぐ。
- 旧版でAI企業が端数の原材料輸送注文（例：0.713単位）を出してしまい、月末検算に失敗する不具合を修正。新規輸送注文数量は整数単位に切り上げ。
