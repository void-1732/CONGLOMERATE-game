# CONGLOMERATE v0.15 — 800技術・分岐／合流研究

- 10研究分野×80技術＝**800技術**に拡張。v0.14までの600技術IDを維持。
- 基礎研究から2〜3の専門枝へ分岐し、別研究との合流および分野横断の前提条件を追加。高級車・軽量車・高性能車・省エネ車などに専門化可能。
- 技術効果は計17種類。追加された12種類は静粛性、熱管理、操縦安定性、乗り心地、部品耐久性、電池長寿命化、電子信頼性、車載UX、安全、多車種生産柔軟性、環境性能訴求、資源循環・省材料。
- 研究前提の存在、参照整合性、循環依存の不存在、JavaScript構文を検証。数値は試作係数。
- セーブデータ移行前にはJSONバックアップを推奨。
