# CONGLOMERATE v0.7 — G2-C / G4-B / G9-B 第1次実装

基本設計書 Ver.3.0／SPEC-001〜094 を維持。設計質問91〜93、SPEC-095以降は未回答・未確定。保留候補 G1・G3・G5・G6・G7・G8 は削除していません。

## 今回の実装

### G2-C 複数株主との交渉・資本政策
- 外部株主を創業株主、機関投資家、分散株主の3ブロックに区分。各株主ブロックの保有比率・売却条件を提示（**試作値**）。
- 買収割合を1%刻みで指定し、希望取得数を満たす複数の売り手が承諾した場合に取引を確定。交渉失敗なら売買・送金なし。
- 少数持分は投資として保有し、議決権過半数の取得時から連結対象にする。35%→55%→65%の段階的買い増しを確認。
- 会社の所有関係、取得元帳、非支配株主持分、連結CF、子会社資金が二重に増えないことを照合。
- 買収金は買い手から売却株主へ支払う。対象会社の現金を増減させない。
- 売却希望価格・株主ブロックの留保条件はゲーム設計上の**暫定係数**。未承認の資本政策を正式SPEC化しない。

### G4-B モデルライフサイクル
- 車両の販売開始からの経過月数・需要上の陳腐化・世代数・旧型在庫を表示。
- フェイスリフト（設計を継承し品質/性能を小幅改善、試作2か月）とフルモデルチェンジ（9項目の新設計を使用、試作5か月）。
- 新型発売後の旧モデルは製造しないが、完成品在庫を残し、月次で外販する。旧型は需要係数が低下し、新型と競争する。
- 旧型在庫がゼロになった月以降に販売終了。原材料、完成品原価、仕訳、CFは旧車種別に維持。

### G9-B 経営委任・中長期計画への基礎実装
- 法人ごとに手動経営／予算制限付き経営委任を切替。
- 成長・利益・品質・技術・均衡の優先方針、販売目標、最低現金残高、月間研究費上限を指定。
- 月次の生産計画・研究予算は設定上限内でAIが調整し、目標・販売実績・利益・現金の月次報告を保存。
- 許可されていない買収・借入・工場建設・採用は自動実行しない。

## 回帰試験とデータ互換
- ChromiumとPlaywrightで G2/G4/G9 の操作を検証。旧v0.6の9項目車両設計・複数工場・6研究分野・販売分析のテストも通過。
- 35%少数持分（非連結）→55%議決権支配（連結開始）→65%追加取得（取得現金を二重計上しない）を複数月で検証。連結BS/CF整合と未実現利益に関する既存処理を維持。
- 120か月の連続処理で、月次会計、資源、連結エラーなし・CF期首期末照合、JSON保存/復元一致を確認。
- 古いセーブに新しい外部株主ブロック、委任設定、車種世代項目がない場合の自動補完を検証。外側の VERSION=1、IndexedDBのDB名・構造を維持。

## 現状の制限・未実装
- **G2-C は部分実装。** 他の法人大株主からの株式譲渡、第三者割当増資による希薄化、自己株式、株式交換、議決権と経済持分の乖離、敵対的買収、支配喪失と再測定は未実装。複数の外部株主との交渉は今版で実装。
- **G9-B は基礎実装。** 予算の年度横断統制・取締役会決裁・部門別委任の高度な実装は残る。
- 車両寿命、開発費、買収価格、交渉成立条件、委任AIの目標関数は暫定値。歴史上の実際の市場統計・会計基準への完全準拠は未達。
- 取得時PPA、正式なのれん・税効果、外貨換算調整勘定等の未解決会計項目は従前どおり残る。
- **IndexedDB実ブラウザ再起動試験は未完了。** テストはブラウザ内の模擬IndexedDB＋JSONで実施。100年以上の長期試験も未実施。
- リポジトリはPublic。保存データや私有情報はコミットしないこと。
