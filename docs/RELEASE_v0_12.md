# CONGLOMERATE v0.12 — UI・自動化・7資材・120技術ツリー

基本設計書 **Ver.3.0／SPEC-001〜094を維持**。設計質問91〜93・SPEC-095以降は未回答、未確定。追加数値は試作パラメータであり、正式SPECではありません。

## 承認済み改善を実装
- **UI**：既存の左側6メニューとページ構造は維持。画面上部のサブナビゲーションをコンパクトにし、研究・人事は個別タブへ。長い研究ツリーは独立した横スクロール領域。
- **独立自動化**：生産計画と研究予算を別々にON/OFF。研究自動化では研究内容も前提を考慮して選定。旧v0.11の経営委任設定を引き継ぐ。既存の価格・仕入先・保守・広告の自動設定も維持。買収・借入・工場建設は無断で自動実行しない。
- **7資材**：鋼材・ゴム・部品セット・アルミニウム・銅・ガラス・化学原料／樹脂。国ごとの価格変動、企業別サプライヤー契約、材料在庫、製造時の消費量と実原価計算に連携。
- **企業を契約先に指定**：調達先を市場にある企業のIDと名称で選択。買収・設立した同国内子会社も候補。販売店・輸出先の契約企業も指定可能。**同国・同通貨で100%支配下の企業から現物在庫を簿価移転するケースで、買い手と売り手双方の資産・現金・仕訳を更新**。
- **研究ツリー**：6研究効果分野に20段階ずつ、計120技術ノード。前後関係と複数分野の前提、年代より先行する研究の大幅な時間ペナルティ。研究者と研究予算の両方に応じて最大4同時枠。車体形状、動力、駆動、安全、内装などの車両設計のロック解除。

## 検証記録
- Chromium / Playwrightによる UIと機能の回帰：**PASS**。120ノードの可視化と研究開始・進捗・完成、研究による車両仕様解放、別々の自動化設定、7資材の仕入先表示、子会社の簿価資材移動、企業販売店契約、会計・連結CFの照合。
- **30社から120か月の継続試験：PASS**。39社まで増加、全月の仕訳検算・連結CF照合。60、90、110か月の保存・読み直しと最終連結BS/CF保存整合を確認。
- **実際のv0.11セーブ移行：PASS**。旧v0.11版のHTMLで4か月進めたセーブデータをv0.12で解析し、7資源在庫・研究ツリーへの補完後、翌月へ進行。財務・連結CFの検算を通過。
- JavaScriptの構文検証と実ブラウザ画面表示を通過。
- **実ブラウザでIndexedDBを閉じて再起動した検証は未実施**。ローカルfile URLはテスト環境が `net::ERR_BLOCKED_BY_ADMINISTRATOR` で遮断。モックDBとJSONについてのみ検証。

## 限界・今後の課題
- 企業別契約は実在ゲーム法人を参照。ただし**外部企業間／越境契約の正式な売り手側収益・在庫・債権債務・相互消去は未実装**。同一国内グループ間では簿価・現物移転で両社の単体仕訳を発生させるが、正式な移転価格・税務会計は未実装。
- 販売店会社の指定は契約相手の情報に反映。ただし代理店の独立した販売損益・製品所有権移動を伴う内部卸売は未実装。
- 研究前倒し倍率・技術間前提・研究枠の人員／資金閾値・原材料使用量は試作値。正式設計上の未確定要件を確定しない。
- 100年以上の連続処理、正式PPA／のれん・各国税務・外貨換算調整勘定は未検証または未実装。
- 正式吸収合併、上場、支配喪失、少数株主との再編は未確定のまま維持。
