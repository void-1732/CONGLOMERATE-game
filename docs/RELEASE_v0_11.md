# CONGLOMERATE v0.11 — Y2=B・Y3=B・X3=B（第1段階）

基本設計書 Ver.3.0／SPEC-001〜094は変更なし。質問91〜93およびSPEC-095以降は未確定。新係数は試作値。

## 新機能と制限
- **Y2=B 事業統合**：同国同通貨の100%完全支配下にある自動車・製造業の直接親子・兄弟会社間で、工場・車種・在庫・従業員・研究権利・ブランド・販路を簿価で譲渡し、全事業を統合。譲受側で外部費用を記録。**旧法人は存続し、株式、取得履歴、現預金、残債務・仕訳を残す。法的吸収合併ではない**。統合済み法人の事業運営と重複する統治費・相乗効果を停止。
- **Y3=B 事業移管**：工場ごとに設備能力按分の試作簿価で設備と関連する従業員、希望時は車両モデルと完成品在庫を移す。双方に複式仕訳、譲受側に外部再編費。持分・議決権は変更しない。外国法人、少数株主、輸送中資産、内部貸付残や孫会社を持つ法人は一部操作で対象外。
- **X3=B 工場間物流**：専門工場で鋼材・ゴムを消費し部品を製造。加工人件費を原価へ加え、拠点別割当在庫を管理。専門工場から完成車・組立工場へ発送し、工場間輸送中材料を貸借対照表の資産として計上、着荷で戻す。輸送運賃は外部費用。組立工場への在庫割当が生産制約に反映。

## 検証
- Chromium/Playwright：専門工場建設→部品製造→発送→到着、完全子会社2社創設、工場および車種移管→全事業統合を実行。単体・連結BS/CF・材料/在庫勘定照合を通過。
- **120か月回帰試験**：60・90・110か月時点でJSON保存／復元を挟んで進行。最終42法人、毎月の会計/CF照合と最後の連結BS/CF保存復元一致を確認。
- **実v0.10保存データ**：v0.10版で3か月処理後の保存JSONをv0.11へ読み込み、翌月を正常処理。
- 既存v0.10の工場立地・経営委任スモークテストも通過。
- **実IndexedDBのブラウザ再起動試験は未完了**。実HTTP接続が `net::ERR_BLOCKED_BY_ADMINISTRATOR` で遮断された。模擬DBとJSON復元のテストは通過。

## 未実装
正式な法律上の吸収合併、旧法人の消滅と全債務の包括承継、少数株主対価・株式交換・株式譲渡、正式なPPA/のれん/税効果、子会社間の材料実売買や移転価格、海外法域税務・通関、全部品の複雑な工程別倉庫・完成車の工場間移送は今回の対象外。承認なしにこれらの会計方針をSPEC化しない。
