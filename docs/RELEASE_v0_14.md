# CONGLOMERATE v0.14 — 統合型600技術ツリーと研究専門化

## 実装内容

- **3つの上位ツリー**：「車両・基盤技術」（動力・車体・材料・蓄電の4分野）、「電子・知能・車両機能」（電子制御・ソフトウェア・安全・快適の4分野）、「生産・産業技術」（生産・環境の2分野）。各上位ツリー内の全分野を**同じ縦横スクロールキャンバス**に表示。分野切替は同一マップ内のジャンプ。
- **600ノード**：既存300ノードのIDと保存データを保持し、各分野に30ノードの並列専門研究を追加。通常枝2〜3／専門枝2〜3、計4〜6研究系統／分野。高級・静粛、軽量、性能、省エネ、電子技術、工場効率に特化可能。
- **分野横断の前提研究**：分野をまたぐ接続202件、上位カテゴリ間の接続120件。別カテゴリの技術が前提の場合は研究詳細から直接移動。研究者・予算・時代による研究枠と未来技術の前倒しペナルティは維持。
- **重点研究の指定**：「均衡」「高級・快適」「軽量・省材」「高性能」「省エネ」「電子・自動運転」「工場効率」。AIの研究選択を誘導。手動研究は任意の前提を満たす技術を選択可。

## 今回追加した実効効果（5種類）

| 効果 | 適用先 | 暫定の最大効果 |
|---|---|---|
| 軽量・省資材 | 鋼材・ゴムの実際の必要量、調達見積りと製造原価 | 鋼材 -16%、ゴム -7.2% |
| 高級市場訴求 | 高級車の需要適合度・販売競争力 | 研究効果指標最大+24%、高級市場適合係数への加算最大+0.144 |
| 燃費・省エネ | 電動・ハイブリッド等の市場適合度と車両性能 | 適合係数最大+0.09、性能最大+3.6点 |
| 電子・知能装備 | 先進安全・運転支援・通信機能の市場適合度と品質 | 適合係数最大+0.09、品質最大+3.2点 |
| 製造歩留まり | 設計時工程負荷と工場の実効生産能力 | 工程負荷最大-0.14、実効能力最大+5.6% |

効果には上限を設定。旧版の性能・品質・生産技術の効果も維持。車両仕様解放は、対象となる**特定の技術IDの取得**を必須とし、別技術の研究数だけで解放されることを防止。

## 検証

- Chromiumにて「車両・基盤技術」240ノード、「電子・知能・車両機能」240ノード、「生産・産業技術」120ノードの表示、専門研究の選択と研究重点保存を確認。
- 全600ノードの前提IDの実在、分野横断の技術関係、研究枠と解放判定を確認。
- 軽量化効果の数値検査：同一車種で鋼材2→1.902単位、ゴム1→0.978単位／台。推定製造原価37,158→36,537円相当（テスト設定）。端数材料を用いた8か月の月次会計・連結CF検算にエラーなし。
- **120か月回帰試験**：初期30社→最終39社。毎月の会計・連結CF検算が通過。60・90・110か月にJSON保存・復元を実施し、連結BS・CF一致を確認。
- **実v0.13セーブ移行**：旧v0.13で作成したJSONを読み込み、旧技術の完了状態、進行中研究の55点、法人・連結CFを維持。
- **未実施**：実IndexedDBをブラウザ終了・再起動しての永続性試験（検証はモックDB＋JSON）。100年以上の耐久試験。
