# CONGLOMERATE Ver.0.23 — 操業・人員診断と外観コンセプト
2026年11月17日 / 開発試作版。Ver.0.22.1の生産・M&A・会計・保存ロジックを継承。

## 工場：低稼働・生産停止の原因分析
- 個別工場詳細に「稼働率・停止原因の分析」を追加。前月稼働率・現在の生産計画・参考人員を明確に区別。
- 停止・低稼働の原因候補として、休止・改修・建設、設備劣化、会社全体の製造人員制約、車種別生産計画、鋼材・ゴム・追加原材料不足、最終組立工場の到着済み3部品不足、支援工場の月次部品製造計画不足を検出。
- 原因候補ごとの対処方法、および人事・生産計画・原材料調達への直接移動を追加。
- 診断は現在の計画・在庫からの推計で、前月の稼働低下原因を厳密に再計算したものではない。

## 工場：種類別の部品・供給情報
- 総合完成車工場：到着部品の在庫と輸送中、最短到着予定、設定済み供給元、前月の各3部品の工場内製数量、前月完成車組立数を表示。到着済み部品を優先し、不足分を原料から内製するVer.0.22.1の方式を維持。
- 最終組立専門工場：エンジン、車体、電子制御の3部品ごとに到着済み数量、輸送中、最も早い到着予定月、設定済み供給元を表示。到着前の部品は組立に使えない。
- 専門部品工場：対象部品の前月製造、工場内在庫、月次製造計画を表示。

## 工場人員・人事
- 人事画面に「製造」「研究」「営業・管理」の実人数・推奨人数・過不足と判定ラベルを表示。
- 工場詳細に会社の製造従業員を設備能力に応じて按分した推計配置人数・必要人数目安を追加。
- **注意：** 会社単位の人員管理を維持。工場別の数字は実際の配属台帳ではなく、推計です。研究と営業の推奨値も経営判断の参考です。雇用は従来の人事画面で管理します。

## 車両外観・商品企画
- 車両設計の10番目の意思決定として「外観コンセプト」を追加。実用重視、スポーティ、高級・上質、先進・未来的、クラシック、個性・独創性、バランスの7種類。
- 外観別に購買層との相性を倍率化し、販売競争力・一部の工程負荷へ反映。数値はゲーム用暫定係数。3D車両画像生成ではない。
- 旧モデルの外観が未指定なら「バランス」として解釈。研究IDや既存車種IDを変更しない。

## 製品・開発の4画面
- 設計・商品企画、生産計画・原価、開発プロジェクト、販売・品質の内部4タブ。
- 既存のモデル改良、グレード、オプション、生産計画、製造原価、品質保証・リコール、在庫・販売を維持。
