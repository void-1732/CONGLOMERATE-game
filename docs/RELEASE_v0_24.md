# CONGLOMERATE Ver.0.24 — 自動経営管理センター・調達契約UI

2026-11-17。Ver.0.23からの互換アップデート。研究800技術、車両開発、詳細工場製造、M&A、新株発行、単体・連結会計、JSON保存形式 `VERSION=1` を継承。

## 1. 自動経営管理センター
企業グループ → 自動運営・AI設定の画面を4タブへ再編：
- **概要**：委任状態、現在の許可済み処理数、工場の自動配送ルート数、最低現金目標、資金不足・低稼働・供給問題の警告、直近実績。
- **自動化設定**：6分野で許可・予算を編集。生産・工場、調達・物流、販売・市場、研究・開発、財務・予算、人事・組織。
- **実行履歴**：AIの実行・提案のみ・見送りの判断と理由、月次支出、従来の委任実績、CSV書き出し。
- **グループ管理**：20社ずつページ送り、法人名検索、個別編集、支配下企業への権限一括変更と確認。100拠点規模の工場別ルートは従来の工場画面へ誘導。

## 2. 既存自動化エンジンとの接続
- 実際に動く機能：生産計画・研究予算、自動価格改定、仕入先最適化、設備保全、広告、既存の工場別自動部品配送。
- 各機能に **OFF / 提案のみ / 予算内で自動実行 / 定型処理を自動実行** の権限を指定。提案のみの場合、保存済みの手動生産計画・車価を上書きしない。
- 追加支出総上限、保全・広告別の月額上限、最低現金目標、研究費上限を既存仕訳・月末AI処理で強制。
- 保存前の差分プレビューと明示的な確定を設置。編集内容は次回月末処理から反映し、旧版セーブの自動化フラグを初期値として移行。
- 勝手な大規模採用、借入、M&A、設備の新設・廃止を許可しない。部品在庫の月次調達、競合AI、自動保存は既存の独立処理として表示。
- **注意**：人事の自動大量採用、長期需要予測の新規モデル、正式な停止日数・原価削減効果の因果推定は本版では未実装。動かない機能に有効なON/OFFを付けず、提案・既存画面への導線と明示。

## 3. 原材料・部品の購入契約のUI・挙動改善
- 従来の狭い表を7資材のカード式UIへ変更。主仕入先・代替仕入先・安全在庫の入力サイズと余白を統一し、在庫・輸送中・単価・供給障害を表示。
- 契約保存前に全7資材の入力を検証してから一括適用。不正な1行によって前の資材だけ保存される部分更新を防止。
- 仕入先を手動変更すると「主仕入先の変更をAIに許可」をOFFにし、次回月末の仕入先最適化で勝手に変更されない。ユーザーが明示的にONへ戻した場合のみ自動で変更可能。
- **保存は即時発注ではない。** 新しい契約・安全在庫係数は次回月次調達で参照される。仕入先能力・必要量・現金・輸送リードタイムで到着時期と数量が制限され、既に輸送中の注文は変更されない。
