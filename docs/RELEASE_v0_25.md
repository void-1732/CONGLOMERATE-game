# CONGLOMERATE Ver.0.25 — 市場・販売網のUI再設計

2026年11月17日 / Ver.0.24とのセーブ互換を維持した開発試作版。

## 製品・開発
- 独立した「開発プロジェクト」タブを廃止。製品画面は「設計・商品企画」「生産計画・原価」「販売・品質」の3タブ。
- 開発中車種の名称、動力・車体、発売までの残り月数は「設計・商品企画」内の展開可能な「開発進捗・発売予定」に移設。
- **`f.projects`、開発費、進行、発売時の車種移行は削除・変更しない。** 旧セーブに含まれる開発中プロジェクトも表示・進行する。

## 市場・販売網
主要6画面を用意し、ユーザー提供の画面構成・色彩を参考に一貫した小型カード、白背景、青アクセント、KPI、短い表、操作導線へ再編。

1. **分析センター**：国内需要・自社グループ実販売・観測販売・現役車種、地域別の需要バー、販売ゼロ警告、競合ウォッチリスト。
2. **地域別市場**：5か国の選択、需要・販売方式・契約上限・観測内構成比、6購買層への需要配分、国別比較表。推計需要と月末確定販売を区別。
3. **競合インテリジェンス**：会社名・所在国・業態による検索、企業名／販売数／車種数ソート、10社ずつページ送り、最大4社の比較。未確定情報をゼロに捏造しない。
4. **販売店・輸出**：国別販売契約を入力・保存可能な5カードへ再編（従来の`channel_<国>`、`dealer_<国>`、`capacity_<国>`と`saveDistribution()`を継続使用）。地域販売法人の設立、輸送中商品の到着見込も維持。
5. **自社グループ**：グループ実販売、現役車種、表示法人の損益、国別販売、法人別業績、販売ゼロ時の確認導線。従来の購買層・広告投資等の詳細台帳は折りたたみに保管。
6. **世界マクロ・詳細**：旧世界市場画面と競合価格表をそのまま維持。

### 輸出採算の試算
- 価格、製造原価、輸送費、仮の関税率・販売手数料、想定台数から概算粗利益を表示。
- **ゲームの注文・価格設定・会計には一切反映しない独立した参考計算**。運賃・関税はユーザーが指定する試算値であり、ゲーム内の国際輸送・決算の実装と混同しない。

### 分析上の注意
- 潜在需要は現在の国別マクロ・景気係数で計算した**市場全体の推計需要**。受注・販売実績ではない。
- 「観測内の販売割合」はゲーム内で月次販売実績が記録された自動車企業の販売台数合計を分母とする参考値。**市場全体シェアではない**。
- 月次処理が未確定の企業は「未確定」を表示し、未確定データを0として扱わない。
- 一部の競合モデル・研究・工場情報はゲーム内部の参照データであり、外部から調べた実在企業の公表値ではない。

## 互換性と検証
- 保存形式`VERSION=1`、研究800技術、M&A、新株発行、AI、製品開発、販売契約、工場詳細製造と自動輸送、連結会計を維持。
- Chromiumで市場画面6種、国変更、検索・絞り込み・比較、地域販売契約保存、輸出試算、製品3タブ、旧開発状況の表示を確認。
- Ver.0.24で生成した実JSONを読み込み、**60か月連続**で単体・連結会計／連結CF検算に異常なし。
- 390px幅で5つの主要市場ページを表示し、全体の横はみ出しなし。競合表はテーブル内で横スクロール。
- 既存のIndexedDB保存・復元コードは変更していないが、ブラウザを閉じて再起動した後の全環境での永続保存は未検証。移行前にJSONバックアップを推奨。

基本設計Ver.3.0と承認済みSPEC-001〜094は変えていません。数値はゲーム用の仮設定です。
