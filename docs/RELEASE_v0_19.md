# CONGLOMERATE v0.19 — 研究操作・名称変更・市場分析

**現行配布本体：`index.html`**（2026-11-16）

## 変更点

1. 同じ月に研究枠の空きがある限り複数の技術を連続開始可能。研究を中止して空き枠を再利用可能（中止した研究進捗は失われる）。
2. 研究ツリー／技術詳細／ページスクロールの位置を保持。下部ノード操作時の画面ジャンプを緩和。
3. 自社・支配子会社の社名変更（38文字以内、他社は不可、同名不可）。工場名変更（32文字以内、対象企業が支配下の場合のみ）。会社・工場の内部IDや株主・会計データは不変。
4. 市場・販売網を「自社グループ分析」「全世界分析」「販売店・輸出」の3タブへ分割。企業・国・購買層・モデル別販売と、世界市場・競合情報を切り分け。

## 互換性と検証

- 800技術、v0.15〜v0.18機能、M&A・AI・会計、保存スキーマVERSION=1を維持。
- v0.16〜v0.18 JSON読み込み、同一ターン5研究開始と中止・再使用、親子会社の名称変更、他社名変更拒否、M&Aと月次会計検算をブラウザで確認。
- 追加した`tests/test_v019_smoke.py`は現行版の800技術・研究連続着手・市場ページ・社名変更・会計検算のスモーク試験。
- 実IndexedDB保存の再起動／復旧は全ブラウザ・全OSでの保証なし。移行前にJSONをエクスポートしてください。
