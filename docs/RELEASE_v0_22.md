# CONGLOMERATE Ver.0.22 — レイアウト・操作性改修
2026年11月17日。Ver.0.21の製造・研究・M&A・会計・AI・保存モデルを変えずに、操作画面を改修した開発版。

## 研究・人事
- 旧版で研究／人事を1つのHTML文字列から切り出して表示していた方式を廃止。研究と人事を独立してレンダリングし、HTMLの入れ子崩れやスクロールの混乱を回避。
- 人事ページを「従業員数」「採用」「給与・技能教育」「労使交渉」「実績」の単位に分離。人事の機能・保存処理は継承。

## 入力コンポーネント
- 入力欄・プルダウン・主要操作ボタンの高さを40px基準に統一。枠線・余白・角丸・フォーカス表示を共通化。
- フォームの列は画面幅で折り返し。チェックボックスのラベル配置を修正。工場の大規模表は横スクロール可能な折りたたみ領域へ格納。

## 企業グループの自動運営・AI設定
- 企業グループに「自動運営・AI設定」タブを設置。法人別の委任運営状態を一覧表示。
- 選択法人の自動生産計画、自動研究費、価格改定、仕入先選択、予防保全、販売促進・広告、予算上限、委任実績ログを編集・確認。
- 研究ロードマップの自動優先はその場でON/OFF可能。工場の自動配送設定は稼働中ルート数を表示し、工場画面へ移動可能。
- 独立AI企業の価格改定・新型車・M&A・増資、ゲーム全体の自動保存は自動機能として説明と参照先を表示。これらはプレイヤーの委任スイッチでは制御しない。

## 工場ワークスペース
- 工場カードの長い羅列を「工場検索＋状態別フィルタ＋20拠点のページ送り」へ変更。
- 工場を1つ選ぶと、名称変更、設備能力・状態・稼働率、担当車種、保全、設備更新、拡張、縮小、休止・再開・廃止、専門部品生産量、個別自動配送先・目標在庫・月間発送上限を詳細で操作。
- 工場の新設、一括専門部品設定、従来の部品製造・輸送、立地比較、材料・製品在庫原価は折りたたみ領域に保持。会計ロジックや工場内部IDは不変。

## 実施した検証
- JavaScript構文検査合格。Chromiumで研究／人事切替、給与設定、自動運営オプション保存、工場49拠点の検索・絞り込み・20件ページ送り、個別ルート保存、休止操作を確認。
- 49拠点で18か月連続の単体／連結会計検算を通過。
- Ver.0.21で作成したJSONを読み込み、研究800項目を保持したまま24か月連続で会計・連結検算を通過。
- 390px幅のモバイル画面でも人事と工場ページの全体横はみ出しなし。
- 未保証：実ブラウザを完全終了・再起動した後のIndexedDB永続復元の全環境試験、全種の旧版自動化シナリオを網羅した長期大規模負荷試験。更新前にJSONバックアップを推奨。

基本設計書Ver.3.0／SPEC-001〜094と旧版の正式設計は変更しない。ユーザー未確定の仕様も変更なし。
