# CONGLOMERATE — 企業経営シミュレーション

**現在の開発試作版：v0.29-dev.3（2026-11-18）**

自動車メーカーの創業から車種開発・製造・研究・市場・企業グループ・M&A・財務までを扱う、単一HTMLで動作するオフライン対応の企業経営シミュレーションです。

> **注意：開発試作版です。** ゲーム内の企業価値、需要、研究効果、費用、会計数値は試作係数によるモデルであり、正式な会計基準に準拠した監査済み財務諸表ではありません。

## 起動方法

- **Windows:** `start-local.bat` を実行し、`http://127.0.0.1:8765/index.html` を開く（Python 3が必要）。
- **macOS / Linux:** `./start-local.sh` を実行し、同じURLを開く（Python 3が必要）。
- または最新のChrome / Edgeなどで `index.html` を直接開く。外部APIは不要です。

**保存データの注意：** `file://`、ローカルサーバー、GitHub Pages は異なる保存領域です。更新前に旧バージョンのゲームからJSONバックアップを書き出し、新しいバージョンにインポートしてください。旧バージョンで新形式の保存データを再読み込みすることは保証されません。保存JSONにはプレイ情報が含まれるため、GitHubへコミットしないでください。

## 現行版 v0.29-dev.3 に含まれる主要機能

- **v0.29-dev.3:** 「法人間の部品売買・使用料」で、同一通貨の法人間で部品を引当・発送・検収・決済できます。採用許諾に設定した使用料は組立で実際に投入した数量で計上し、内部取引と未販売品に残る利益は連結で消去します。

- **v0.29-dev.2:** 承認済みの部品表（BOM）を車種・組立工場に割り当て、部品ラインから製造したロットを同一法人内で輸送して完成車へ組み込めます。材料・加工費・運賃を部品ロットへ記録し、完成車の組立と販売原価まで追跡します。

- **v0.29-dev.1:** 「工場 → 設備・人員設定 → 部品ライン・設備投資」で工場内の部品ラインを増設・改修・増強できます。承認した工事は建設仮勘定へ計上し、竣工検査の合格後に固定資産へ振り替えます。AIは設備投資を提案し、プレイヤー支配下の法人での着工はプレイヤーが承認します。

- **v0.28-dev.3:** 「部品設計・適合検査 → 共同開発・部品ライセンス」で、同一通貨のグループ法人が共同開発の分担率を承認し、試作・試験費を月次で精算できます。部品の版ごとに閲覧・車両への採用・工場での製造を個別に許可できます。採用済みの設計承認には、その時点の許諾を記録します。

- **v0.28-dev.2:** 設計画面でエンジン・モーター、変速機、車台、車体、電子装備、電池を開発できます。完成した部品は版を指定して車両構成に採用・流用できます。適合検査から修正開発を申請し、新版への差し替え後に設計承認できます。

- **v0.28-dev.1:** 人事で製品設計技術者を採用し、設計教育予算を設定できます。製品・開発の設計画面から準備案件を申請・承認し、自動配分または固定配属で月次の工数・試作費を管理できます。既存の車種開発に加え、後続の部品設計に使う専用枠です。旧セーブの設計人員は0人から開始します。

- **v0.27.1:** 総合・組立工場ごとの実配置製造人員を設備能力へ反映し、ゼロ人の工場では完成車を生産しない。生産計画を工場へ比例配分し、先頭工場への偏りを修正。企業グループの株主・資本政策に外部株主からの自社株買い、自己株式の保有・消却、議決権再計算を追加。
- **v0.27:** 部品仕様・ライセンス・共同開発・注文・輸送・取引・AI投資の空台帳を追加。旧JSONのチェックサム・冪等移行と参照整合性検査を実装。既存車種は従来の生産・原価のまま。**新BOM量産や部品売買はまだ実装していません。**
- **v0.26:** 工場別の製造従業員の自動・固定配分、部品工場の人員制約、部品計画を含む原材料調達、安全在庫・入荷・消費・不足の可視化、上限付き緊急調達、工場詳細3タブによる省スクロールUI。古い共通部品方式も維持。
- **v0.25:** 製品の独立「開発プロジェクト」タブを廃止（設計画面内の開発進捗で機能は保持）。市場・販売網を分析センター／地域別市場／競合インテリジェンス／販売店・輸出／自社グループ／世界マクロ・詳細に整理。需要推計と月末販売実績を区別し、競合検索・最大4社比較・地域販売契約カード・参考輸出採算シミュレーターを追加。
- **v0.24:** 企業グループに**自動経営管理センター**を実装。概要・自動化設定・実行履歴・グループ管理の4タブ、6分野、既存処理に接続した機能別権限、月額の支出上限・現金留保、操作前の差分確認、法人ごとの設定・複数法人への一括適用、AI判断ログとCSV出力。原材料・部品7資材の購入契約をカード式へ刷新し、入力サイズを統一。手動変更した仕入先をAI最適化が勝手に戻さない固定設定を追加。
- **v0.23:** 工場の稼働率低下・停止原因候補を計画・人員・設備・材料・部品供給から診断。総合完成車工場の内製実績と組立工場の到着在庫・輸送中・到着月を表示。人事に製造・研究・営業の過不足目安、工場には推計人数を表示。車両の外観コンセプト7種類を購買層の適合度に反映し、製品・開発を4タブに分割。
- **v0.22.1:** 総合完成車工場が詳細製造モードでエンジン・車体・電子部品を工場内製造して同月完成車組立に使用可能。到着済み3部品セットを優先消費、不足分を鋼材・ゴムと加工賃金で内製。最終組立専門工場は従来どおり到着部品が必要。工場詳細に内製実績・原材料不足・調達導線を追加。
- **v0.22:** 研究・人事の画面構造を作り直してレイアウト崩れを修正。入力欄・プルダウンの高さ・余白を40px基準に統一。企業グループに「自動運営・AI設定」タブを追加し、委任・自動研究・価格・調達・保全・広告・工場自動配送等を集約。工場一覧を検索・種別／状態フィルタ・20拠点ごとのページ送りと個別詳細へ刷新。従来の一括管理は折りたたみに移動。
- **v0.21:** 工場の設備更新・拡張・縮小・休止・再開・廃止、エンジン・車体・電子モジュールの個別製造・工場別在庫・組立消費。支援工場から組立工場への目標在庫に応じた自動輸送。輸送費・納期は同一地域＜国内別地域＜海外。月次中断時の工程・対象企業・原因・復旧手順を示す診断画面とログ出力。AI調達の端数発注による月末エラーを修正。
- **v0.20:** AI企業による競合車種・価格戦略、供給企業ごとの設備故障・輸送遅延・原材料不足、代替仕入先と安全在庫、**銀行・機関投資家・公的機関・個人向けの新株発行と株主希薄化**。現金・資本金・持分を連動。買収済み子会社の支配割合も再計算。
- **v0.15:** 3上位カテゴリ・10研究分野・**800技術**。分岐・合流・分野横断の前提条件、17種類の累積研究効果。
- **v0.16:** 研究ロードマップ（最大3目標）、前提研究の逆算・自動優先、概算研究期間、36か月の研究履歴、経営診断。
- **v0.17:** 車種5グレード・6オプション（最大3選択）、6購買層別市場需要、品質保証・検査・自主リコール。
- **v0.18:** M&A候補の国・業態・評価額等による絞り込み、買収価格試算と外部株主交渉、AI企業の買収、6か月の買収後経営統合（PMI）。企業保有株式と外部株主を区別。
- **v0.19:** 同一月の空き枠への連続研究開始・中止、研究ツリーと詳細のスクロール位置保持、**自社・支配下子会社の社名／工場名変更**、市場分析を「自社グループ分析」「全世界分析」「販売店・輸出」に分割。
- 既存の工場、生産、材料調達、販売、法人会計、連結会計試算、JSON保存・復元および多層企業グループ機能を継承。
