# CONGLOMERATE — 企業経営シミュレーション

**開発試作版 v0.4**（2026-11-16）

自動車メーカーを創業し、製品・工場・研究・人事・市場・財務を管理しながら、他業種への進出・買収・多階層持株会社の経営を目指すブラウザ向け企業経営シミュレーションです。

> **開発中の試作版です。** 正式な企業会計基準に準拠する完成製品ではありません。設計済みの全94仕様を実装済みと示すものではありません。

## 起動方法

**Windows:** `start-local.bat` を実行し、`http://127.0.0.1:8765/index.html` を開く。Python の導入が必要です。

**macOS / Linux:** `./start-local.sh` を実行し、同じ URL を開く。Python 3 が必要です。

単一ファイル `index.html` を直接開くこともできますが、`file://` と `http://127.0.0.1:8765` は**別の保存領域**です。移行時はゲーム内のJSONエクスポート／インポートを利用してください。

## 現時点の主な実装

- 創業条件と基本的な会社経営・月次処理
- 自動車製造、研究、人事、取引および経営情報の試作
- 企業買収・子会社・孫会社の管理と帳簿価額ベースの連結財務**試算**
- 内部貸付・内部売買の消去、未実現利益、非支配株主持分の一部計算
- 取得時スナップショットと連結CFの期間整合、現金の為替換算差の検算
- IndexedDBベースの世代保護型保存・JSONバックアップ、実機診断ボタン

## 保存データについて

この版はローカルブラウザの IndexedDB を使います。ブラウザデータ削除、別オリジンへの移動、端末故障には備えられません。**更新前にゲーム内のJSONバックアップを外部へ保存**してください。保存JSONにプレイ履歴・企業名等が含まれ得るため、このリポジトリへコミットしないでください。

## 開発とテスト

- `index.html` : 現行v0.4の配布HTMLをそのままコピーしたゲーム本体
- `tests/` : Playwright を使用する補助的な試験（実機IndexedDB試験を保証するものではありません）
- スクリーンショットは配布用ZIPに収録（GitHubにはゲーム本体・検証資料を優先登録）

PlaywrightのテストにはPython環境で `pip install playwright` と `python -m playwright install chromium` が必要です。ローカルにChromiumがある場合、環境変数 `CHROMIUM_EXECUTABLE` を指定して使用できます。
